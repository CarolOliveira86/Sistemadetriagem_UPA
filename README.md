# Sistemadetriagem_UPA

 Sistemadetriagem_UPA

detalhando como cada um dos 10 requisitos foi contemplado;
- Uso apenas do nome como string e demais dados no arquivo do script.ts
- Uso de botões com elementos gráficos universal para clicar se o paciente é urgente ou não
- Uso do if para a condição ser true ao submeter o nome do paciente e demais dados
- Uso do arrow function para o envio do formulário, ao invés de repetir a palavra function ela simplifica
- O sistema idenfitica sua urgencia ao enfermeiro(a) clicar em um dos botões de cores diferentes (vermelho o mais grave e o azul o mais brando)
- inserido o package j.son apenas de forma básica, possuo pouco dominio ainda (este tópico admito que tenho q aprofundar mesu estudos)
- usar o node.test foi um verdadeiro desafio. usei muita ia e os videos para entender
- -adicionei apenas o pacote básico.

- Clicar em finalizar e encaminhar
